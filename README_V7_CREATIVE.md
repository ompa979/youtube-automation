## Script contract
1. Hook — specific misconception/consequence/curiosity
2. Context — only the facts needed
3. Mechanism — cause/effect or rule
4. Example — one worked example
5. Exam takeaway — exact cue to recognize/apply the answer
6. Memory lock — one save-worthy recall rule

55-85 spoken words. No A/B game, countdown, fake urgency, filler or generic motivational intro.

## Topic intelligence
`EXAM_ONLY=true` hard-blocks lifestyle/consumer topics. Candidates are ranked using YouTube autocomplete, Google Trends, SEO cluster fit, exam fit, teachability, value density, visual mechanism potential and duplicate protection.

## Thumbnail contract
AI hero art first, then deterministic Pillow typography. Ten visual archetypes, three candidates, automatic composition/contrast scoring, 1280x720 JPEG. The AI image contains no text; all typography is rendered locally.
