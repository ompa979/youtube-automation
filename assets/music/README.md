# Background Music (Optimization #6)

Place royalty-free MP3 tracks here. The pipeline picks the first .mp3 found.

## Free sources (no attribution required):
- https://pixabay.com/music/search/lofi/   → search "lofi study"
- https://pixabay.com/music/search/ambient/ → search "ambient soft"

## Recommended tracks for educational content:
- Slow lofi beats, 70-85 BPM
- No lyrics
- Volume is auto-ducked to 3.5% so it never overpowers the voice

## Naming convention:
  lofi_study_1.mp3
  lofi_study_2.mp3
  ambient_soft_1.mp3

The pipeline uses the first track alphabetically.
Add multiple tracks — the pipeline rotates through them in future updates.
